# Brand Assets

- `logo.svg` — original rider-and-lance artwork as supplied, full 1254×1254
  canvas with its own cream background square.
- `logo-mark.svg` — the same artwork cropped tightly to the illustration
  (transparent background) via `viewBox="212 247 886 722"`. Used across the
  site by `LogoMark` in [src/components/Logo.tsx](../../src/components/Logo.tsx).

`src/app/icon.svg` (the favicon) is a separate derived file: the same path
data recolored to a single tone on a bronze rounded-square background, sized
for small favicon rendering.
